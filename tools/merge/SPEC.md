# 多批次結果彙整 — 工具規格書（tools/merge/SPEC.md）

本文件為「**濫用藥物實驗室工具箱**」工具「**多批次結果彙整**」的專屬規格書，並完全遵守工具箱根目錄 [SPEC.md](../../SPEC.md) 的共同規範。

---

## 1. 工具基本資訊

- **工具名稱**：多批次結果彙整
- **工具 ID / 路徑**：`merge`（`/tools/merge`）
- **所屬分類**：`上課工具`
- **核心用途**：一次彙整多週／多批次農藥殘留檢測檔案，自動對應不同人員匯出的欄位與農藥名稱寫法，產出「彙整總表」與「超標清單」。

---

## 2. 輸入格式與容許量來源

1. **多批次檢測檔上傳**：
   - 支援一次選擇並上傳多個 `.csv`（自動處理 `UTF-8`、`UTF-8 with BOM`、`Big5` / `CP950`）、`.xlsx`、`.xls` 批次檔。
2. **容許量對照表**：
   - 系統內建預設容許量與 LOQ 對照表（對應 `pesticide_limits.csv`）：

| 農藥名稱 | 示範容許量 (mg/kg) | LOQ (mg/kg) |
| :--- | :---: | :---: |
| `Carbofuran` | `0.02` | `0.01` |
| `Imidacloprid` | `0.5` | `0.01` |
| `Acetamiprid` | `0.2` | `0.01` |
| `Chlorpyrifos` | `0.05` | `0.01` |
| `Fipronil` | `0.005` | `0.01` |

   - 頁面保留選填欄位，讓使用者可上傳自訂容許量對照檔（`.csv` / `.xlsx` / `.xls`）來覆蓋預設值。

---

## 3. 欄位對應與名稱標準化規則

- **批次代號擷取**：自動從上傳檔名擷取日期後 4 碼作為 `批次`（例如 `batch_20260920.csv` → `0920`、`batch_20260927.csv` → `0927`、`batch_20261004.csv` → `1004`）；若檔名無日期格式則顯示原檔名（不含副檔名）。
- **多格式欄位對應**（自動去除欄位名稱前後空白）：
  - `樣品`：`Sample ID`、`SampleID`、`樣品`、`樣品編號`
  - `基質`：`Matrix`、`基質`
  - `農藥`：`Analyte`、`化合物`、`農藥`
  - `濃度 (mg/kg)`：`Calc Conc (mg/kg)`、`Conc. mg/kg`、`濃度 (mg/kg)`
  - 選用欄位（若存在則一併保留）：`Area` / `Peak Area`、`IS Area` / `ISTD Area`
- **農藥名稱標準化**：
  - 所有欄位值一律自動去除前後空白。
  - 農藥名稱**忽略大小寫**比對對照表，並統一轉為標準寫法（例如 `CARBOFURAN` → `Carbofuran`、`IMIDACLOPRID` → `Imidacloprid`）。

---

## 4. 超標判定與防呆邏輯

1. **`<LOQ` 處理**：
   - 當濃度欄位為 `<LOQ`（忽略大小寫與前後空白）或非數值之低於定量極限標記時，判定結果為 `<LOQ`，**不列入超標**（即使 `Fipronil` 的示範容許量 `0.005` 小於 `LOQ 0.01` 亦同）。
2. **數值比對**：
   - 可量化數值 **大於（`>`）** 該農藥之 `示範容許量 (mg/kg)` → 判定結果標記為 **`超標`**，並收入「超標清單」。
   - 可量化數值 **小於等於（`≤`）** `示範容許量 (mg/kg)` → 判定結果標記為 `正常`。
3. **例外與防呆**：
   - 若上傳的批次檔缺少上述必要對應欄位，立即攔截並以繁體中文明確提示缺少哪一欄。
   - 若批次中出現對照表找不到的農藥名稱，判定結果標記為 `未定義容許量`，不中斷整體彙整。

---

## 5. 畫面顯示與輸出規範

- **工具頁面內容**：
  - 提供簡短使用說明與欄位對照說明。
  - 上傳成功後，於結果區上方顯示摘要統計：**匯整批次數**、**總檢驗筆數**、**`<LOQ` 筆數**與**超標筆數**。
- **兩張結果表格**：
  1. **超標清單**：欄位為 `批次`、`樣品`、`基質`、`農藥`、`濃度 (mg/kg)`、`示範容許量`。
  2. **多批次彙整總表**：欄位包含 `批次`、`樣品`、`基質`、`農藥`、`濃度 (mg/kg)`、`示範容許量`、`LOQ (mg/kg)`、`判定結果`。
- **匯出與共用紀錄**：
  - **下載 Excel (`.xlsx`)**：匯出單一 Excel 檔，內含兩個工作表：`超標清單` 與 `彙整總表`。
  - **下載 CSV (`.csv`)**：分別提供「下載超標清單 CSV」與「下載彙整總表 CSV」。
  - 提供**列印／另存 PDF** 按鈕，並可勾選「儲存至實驗室歷史紀錄」（呼叫工具箱共用 `save_history()` 寫入伺服器資料庫）。
