# 稀釋與單位換算 — 工具規格書（tools/units/SPEC.md）

本文件為「**濫用藥物實驗室工具箱**」第一個工具「**稀釋與單位換算**」的專屬規格書，並完全遵守工具箱根目錄 [SPEC.md](../../SPEC.md) 的共同規範。

---

## 1. 工具基本資訊

- **工具名稱**：稀釋與單位換算
- **工具 ID / 路徑**：`units`（`/tools/units`）
- **所屬分類**：`上課工具`（於工具箱新增此分類，顯示於首頁卡片與側邊導覽列）
- **核心用途**：讀取儀器匯出的微量元素上機濃度表，依樣品類型（水樣、土壤、食品）自動統一單位並換算為報告濃度。

---

## 2. 輸入格式與前處理

- **支援檔案格式**：`.csv`（自動處理 `UTF-8`、`UTF-8 with BOM`、`Big5` / `CP950`）、`.xlsx`、`.xls`。
- **必要欄位**：
  1. `樣品編號`
  2. `樣品類型`
  3. `元素`
  4. `上機濃度`
  5. `單位`
  6. `稀釋倍數`
  7. `定容體積 (mL)`
  8. `樣品重 (g)`
- **資料清理規則**：所有欄位值於讀取與計算前，一律自動去除前後空白字元（例如 `"W-107 "` 清理為 `"W-107"`）。

---

## 3. 單位識別與標準化規則

讀取 `單位` 欄位時，**忽略大小寫與前後空白**，僅支援以下 7 種寫法（不支援其他單位）：

| 原始單位寫法 | 標準化對應 | 換算基準 |
| :--- | :--- | :--- |
| `ug/L`、`µg/L`、`UG/L`、`ppb`、`ng/mL` | **µg/L** | `1 µg/L` = `0.001 mg/L` |
| `mg/L`、`ppm` | **mg/L** | `1 mg/L` = `1000 µg/L` |

> 注意：微符號 `µ`（U+00B5）與希臘字母 `μ`（U+03BC）皆視為同一微克符號處理。

---

## 4. 計算公式與精度規範

- **稀釋倍數預設值**：若 `稀釋倍數` 欄位為空白，預設視為 `1`。
- **水樣**（報告單位：**`µg/L`**）：
  $$\text{報告濃度 (}\mu\text{g/L)} = \text{上機濃度（統一為 }\mu\text{g/L）} \times \text{稀釋倍數}$$
- **土壤與食品**（報告單位：**`mg/kg`**）：
  $$\text{報告濃度 (mg/kg)} = \frac{\text{上機濃度（統一為 mg/L）} \times \text{稀釋倍數} \times \text{定容體積 (mL)}}{\text{樣品重 (g)}}$$
- **小數位數**：計算完成之 `報告濃度` 統一四捨五入至**小數點後 3 位**（`0.000`）。

---

## 5. 例外處理與防呆規則

1. **整份檔案層級錯誤**：
   - 若檔案為空、格式不符、無法解碼或缺少任一必要欄位，立即攔截並於畫面上顯示清楚的繁體中文錯誤訊息，不寫入歷史紀錄。
2. **單列異常不中斷**：
   - 若單一資料列發生以下情況，**整份檔案繼續換算**，該列 `報告濃度` 留白，並在 `狀態／備註` 欄清楚標註原因：
     - `上機濃度` 為空白或非有效數字（標註：`缺少上機濃度` 或 `上機濃度格式錯誤`）
     - `單位` 空白或不在支援清單內（標註：`缺少單位` 或 `不支援的單位：<原值>`）
     - `樣品類型` 不是 `水樣`、`土壤` 或 `食品`（標註：`不支援的樣品類型：<原值>`）
     - `稀釋倍數` 填寫了非有效數字或小於等於 0（標註：`稀釋倍數格式錯誤`）
     - 固體樣品（`土壤`／`食品`）缺少 `定容體積 (mL)` 或 `樣品重 (g)`，或數值非有效數字／小於等於 0（標註：`缺少定容體積或樣品重（或數值異常）`）
   - 正常完成換算之資料列，`狀態／備註` 標註為 `正常`（或留空）。
3. **畫面上方摘要提示**：
   - 換算完成後，於結果區上方顯示總筆數、成功換算筆數與異常筆數，方便實驗室人員快速覆核。

---

## 6. 畫面與輸出規範

- **工具頁面內容**：
  - 頂部提供簡短「**使用說明**」與「**預期輸入欄位範例**」。
  - 提供檔案上傳表單、選填「備註」欄與「儲存至實驗室歷史紀錄」勾選框（預設勾選）。
- **結果表格欄位**：
  - 保留原始 8 欄：`樣品編號`、`樣品類型`、`元素`、`上機濃度`、`單位`、`稀釋倍數`、`定容體積 (mL)`、`樣品重 (g)`
  - 於後方新增 3 欄：`報告濃度`、`報告單位`、`狀態／備註`
- **匯出與共用紀錄**：
  - 直接提供本次換算結果的 **`.xlsx`** 與 **`.csv`** 下載，以及**列印／另存 PDF** 按鈕。
  - 若勾選「儲存至實驗室歷史紀錄」，呼叫工具箱共用 `save_history()` 寫入伺服器資料庫（自動帶入處理人員、時間、原始檔名／批號與工具名稱）。
